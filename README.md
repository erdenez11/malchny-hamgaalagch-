# Малчны хамгаалагч — камераар амьтан таних

Ноутбукийн камераар 9 анги амьтныг таниж, махчин ойртоход дохио өгч, бүх илрүүлэлтийг Excel-д бүртгэнэ.
Вэб хуудас (`index.html`) дээр хэн ч камераар эсвэл зураг оруулж шууд туршиж болно.

Хичээл: I.ETC320 Эрчим хүчний мэдээллийн систем ба хиймэл оюун ухаан

---

## 1. Систем хэрхэн ажилладаг

```
Камер -> шар хайрцаг (ROI) -> CNN (MobileNetV3-Small) -> x (D = 576 тоо) -> Logistic Regression -> p (9) -> P(аюул) ≥ T ? -> дохио, Excel
```

| Хэсэг | Үүрэг | Сургадаг уу |
|---|---|---|
| **CNN** (нүд) | ImageNet дээр сурсан бэлэн сүлжээ. Зургийг D тоот вектор x (embedding) болгоно | Үгүй (transfer learning) |
| **Logistic Regression** (тархи) | x-ээс 9 ангийн магадлал p гаргана | Тийм: W (9 × D), b (9) |
| **Шийдвэрийн дүрэм** | Махчдын магадлалын нийлбэр ≥ T бол дохио | T-г cross-validation-оор сонгоно |

| Бүс | Ангиуд (хавтасны нэр) |
|---|---|
| Аюулгүй | Адуу (horse), Үхэр (cattle), Хонь (sheep), Ямаа (goat), Тэмээ (camel), Нохой (dog) |
| Аюултай | Чоно (wolf), Баавгай (bear), Ирвэс (snow_leopard) |

### Томьёо

```
z_k = w_k · x + b_k                        k = 1..9  (ангийн оноо)
p_k = e^(z_k) / Σ_j e^(z_j)                softmax: p ≥ 0, Σ p = 1
P(аюул) = p_чоно + p_баавгай + p_ирвэс  ≥  T  ->  ДОХИО
```

**Жишээ (тоо зохиомол):** z(чоно) = 2, z(нохой) = 1, бусад 7 анги = 0
→ Σ e^z = 7.389 + 2.718 + 7 = 17.107
→ p(чоно) = 7.389 / 17.107 = 0.432, p(нохой) = 0.159, бусад тус бүр 0.058
→ P(аюул) = 0.432 + 0.058 + 0.058 = 0.549 ≥ T = 0.45 → **ДОХИО**

Хамгийн өндөр анги ердөө 43% байсан ч P(аюул) 55% болж байна. Тиймээс шийдвэрийг хамгийн их анги биш, P(аюул) гаргадаг.

### Үнэлгээ

| Хэмжүүр | Томьёо | Утга |
|---|---|---|
| Accuracy | зөв / нийт | 9 ангийн ерөнхий нарийвчлал |
| **Аюултай recall** | TP / (TP + FN) | Махчныг хэр алдалгүй илрүүлсэн — **хамгийн чухал** |
| False alarm | FP / (FP + TN) | Малыг махчин гэж хэр андуурсан |
| Босго T | CV дээр recall ≥ 95% байх хамгийн өндөр T | Recall ба false alarm-ын тэнцвэр |

Чоныг "хонь" гэж алдах нь хонийг "чоно" гэж андуурахаас хамаагүй аюултай. Иймээс recall-ийг accuracy-аас дутуугүй чухалчилсан.

## 3. Ажиллуулах (PyCharm)

Файл дээр **баруун товч → Run**, эсвэл Terminal-д:

```
pip install -r requirements.txt      # нэг удаа
python extract.py                    # зураг -> features.npz (хэдэн минут)
python train.py                      # сургах -> model.pkl, Excel, confusion_matrix.png, model/
python live.py                       # камераар таних
python check_image.py zurag.jpg      # нэг зургийг алхмаар бодох
python calibrate.py                  # (заавал биш) камерын калибровк
```

`live.py` товчлуур: **Q** гарах, **S** Excel-д бичих, **F** ROI ↔ бүтэн кадр, **U** гажилт засах асаах/унтраах, **[ ]** босго T-г өөрчлөх.

Зураг нэмэх бол `python collect.py` ажиллуулна (1–9 = анги, SPACE = автомат, C = нэг зураг, Q = гарах).
Дараа нь `extract.py` → `train.py`-г дахин ажиллуулна.

**Анхаар:** код ажиллах үед Excel-ийг хаасан байх ёстой.

## 4. Excel (`animals.xlsx`)

Багшийн шаардлага: файлыг урьдчилан бэлдэнэ. Код файл үүсгэхгүй, хуудас устгахгүй, **зөвхөн заасан нүдийг** шинэчилнэ.
Гарчиг буруу бол код юу ч бичихгүйгээр аль нүд буруу байгааг хэлнэ.

| Хуудас | Хэн бичих | Юу бичигдэх |
|---|---|---|
| `log` | `live.py` | Огноо, цаг, амьтан, монгол нэр, магадлал %, P(аюул) %, бүс, шалтгаан (2-р мөрөөс доош) |
| `toollogo` | `live.py` | Анги бүрийн нийт тоо (D2:D10), сүүлд харсан цаг (E2:E10) |
| `unelgee` | `train.py` | Accuracy, recall, false alarm, T (B4:B15); анги тус бүр (C19:F27); босгоны хүснэгт (B31:E49); загваруудын харьцуулалт (B53:F55); confusion matrix (B59:J67) |
| `gar_tootsoo` | `train.py`, `check_image.py` | z_k (C6:C14), sklearn-ийн p_k (F6:F14), T (B18). e^z, p_k, P(аюул), шийдвэрийг **Excel-ийн томьёо** бодно |

`gar_tootsoo`-ийн томьёонууд (6-р мөрөнд бичээд 14 хүртэл чирнэ):

| Нүд | Томьёо |
|---|---|
| D6 | `=IF(C6="","",EXP(C6-MAX($C$6:$C$14)))` |
| E6 | `=IF(C6="","",D6/$D$16)` |
| G6 | `=IF(C6="","",ABS(E6-F6))` — ≈ 0 байх ёстой |
| D16 | `=SUM(D6:D14)` |
| B17 | `=SUM(E12:E14)` — P(аюул) |
| B19 | `=IF(B17>=B18,"ДОХИО","аюулгүй")` |

Excel-д диаграм бүү оруул: openpyxl диаграмыг хадгалж чаддаггүй.

## 7. Хамгаалалтад заавал ойлгосон байх зүйлс

1. **Хэмжээ:** x = D (576), W = 9 × D, b = 9, p = 9. Сургалтаар зөвхөн W, b олдоно (9·576 + 9 = 5 193 тоо). CNN өөрчлөгдөхгүй.
2. **z = w·x + b ба softmax:** `check_image.py`-аар нэг зургийг бодоод Excel `gar_tootsoo`-той тулга.
3. **Яагаад P(аюул) = гурван махчны нийлбэр:** хамгийн их анги нохой байсан ч махчдын нийлбэр ≥ T бол дохио.
4. **Recall vs accuracy:** махчныг алгасах нь хамгийн үнэтэй алдаа → T-г recall ≥ 95%-иар сонгосон.
5. **Train / test / CV:** C ба T-г train дотор cross-validation-оор сонгосон; test-ийг (20%) зөвхөн эцэст нь ашигласан.
6. **Тольдсон зураг (flip):** зөвхөн сургалтад нэмсэн, test-д ороогүй.
7. **live.py-ийн тогтворжуулалт:** TTA (эх + толь), 5 таамгийн дундаж, 3 удаа дараалан ижил гарч байж тоолох, hysteresis (T-д асаж T − 0.05-д унтрах).
8. **Вэб:** CNN → ONNX, W, b → JSON; браузер ижил томьёогоор боддог.
